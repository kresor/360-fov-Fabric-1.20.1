# 360 FOV Fabric 1.20.1 experimental backport

Attempt 5 is a clean 1.20.1-specific renderer rewrite, not a line-by-line compile of the Minecraft 26.x renderer source.

Target: Fabric 1.20.1, Java 17.

Default projection setting: `120` in `config/fov360-1.20.1.properties`.

This is still experimental. Build with `./gradlew build` or use the included GitHub Actions workflow.
